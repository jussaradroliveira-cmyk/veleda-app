# Aviso de interface sobre dados pessoais e uso de IA

Evite incluir na pergunta nomes completos, documentos ou dados de terceiros. A pergunta e as cartas são enviadas ao fornecedor de IA sem nome, e-mail ou identificadores da sua conta, exclusivamente para gerar a leitura.
